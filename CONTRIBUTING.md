# Contributing

Thanks for helping improve this skill.

## Ground rules

1. **Do not add unverified claims.** Anything about Moon Animator 2 menus, import/export formats, MCP tools or Roblox APIs must come from something you checked (current documentation or your own testing). If it varies by version, say so and label it *assumed*.
2. **Keep the honesty contract.** Instructions must never encourage Claude to claim actions it did not perform.
3. **No copied third-party material.** Do not paste text, code or assets from Roblox documentation, Moon Animator 2 or other sources. Write your own wording.
4. **Keep `SKILL.md` lean.** Put detail in `roblox-moon-animator-2/references/` and link to it from the table at the bottom of `SKILL.md`.
5. **Frontmatter must stay valid**: `name` (lowercase, hyphens) and `description` (what it does and when to use it).

## Pull requests

- One focused change per PR; describe what you tested and in which environment.
- Update `CHANGELOG.md`.
- If you changed a Luau snippet, say whether you ran it in Roblox Studio.

## Reporting problems

Open an issue with the prompt you used, what Claude did, what you expected, and which tools were available in your session.
